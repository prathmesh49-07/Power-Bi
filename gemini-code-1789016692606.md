## 📌 1. Essential SQL Queries

### The Standard Query Order
```sql
SELECT column_1, COUNT(*)
FROM table_name
WHERE condition
GROUP BY column_1
HAVING COUNT(*) > 5
ORDER BY column_1 DESC
LIMIT 10;
